# SEMANTROPIC TD — T3-B · PROPOSAL C: FIRST PLAYABLE ART PASS

19 Oct 2026 · **Experimental Phaser 4.2.1/WebGL2 vertical slice only; NOT the official campaign.**

## Decision record
The director approved C: painterly scene, materials and atmosphere of Concept A combined with decisive silhouettes, personality, effects and mobile legibility of Concept B. External Tower Defense references establish a *quality target*, not reusable assets.

## Implementation (real source files)
- `public/t3b/index.html`: mobile landscape fullscreen responsive DOM UI. Arena takes available viewport, no right permanent inspection column. Top HUD with life/gold/wave, pause/speed; bottom action buttons; directional modes; dismissible context card; safe-area gutters; portrait notice and orientation-related pause.
- `public/t3b/art-c.js`: original programmatic/painterly textures. Background (master canvas 2560×1536) explicitly follows the **T2-C simulation path**; varied greenery, 3 canopy families, stones and ruins, lanterns and wood/stone pathways. Four tower masters 680×720, with original volumetric surfaces and distinct accents. Three enemy types: 8 walking poses, 500×536 each. Infantry: 8 poses, 480×530 each.
- `public/t3b/scene.js`: T2-C Phaser prototype isolated and extended to consume the new masters, two defenders that can both block/attack, damage-bound enemy HP bars and a silver shield for the heavy demo enemy, impact-bound effects and selection dismissal. The game is still a **demo with its own five practice waves**.
- `public/t2c/**`, `public/JUEGO_V5_CANVAS.html`, `public/JUEGO_V5_IPHONE.html`, `main`/T1, PixiJS: **not modified**.

## Quality principles & known limits
- No Kingdom Rush art or concept images are copied or used as full-screen backdrop.
- Route geometry in this experimental scene uses the T2-C pilot path, not a certified reproduction of M01 campaign path; tests on 140-wave Canvas rules are out of scope.
- Hero/Control tower not migrated or automated; no major gameplay changes to official project.
- The selected context menu is informative only, not a complete construction/evolution/branch UI.
- Four regular towers are active, with visible fire/ice/shell interactions. Actual demo impacts, not a pre-recorded still.
- Big gains target illustrated terrain/materials, unit frame count, visible combat, and full-width mobile HUD. An art director must still validate real rendered frames and mobile interaction.

## QA protocol (DO NOT conflate build with execution)
- `new Function(source)` parsing of `art-c.js` and `scene.js`: JavaScript syntax verified in connector V8.
- GitHub commits: branch `art/t3b-propuesta-c`, listing source and protected untouched components.
- Render: independent static staging builds `npm install --no-audit --no-fund && npm run build` and serves `dist`. Logs prove packaging/version, not GPU runtime.
- **Browser visuals**: verify with actual screenshots before artistic sign-off. Chromium QA not guaranteed by CI. Actual WebGL2 uses runtime getContext('webgl2') and instanceof check in `scene.js`.
- **Mobile physical devices**: pending director/device QA; do not claim success from CSS analysis.
- **No FPS benchmarks requested or executed** in T3.

## Minimum human smoke tests
1. Browser opens T3-B without blocker; in diagnostics engine shows Phaser 4.2.1, WebGL2 string exists.
2. Landscape map fills available game display; no fixed sidebar.
3. Four visibly distinct towers; touch tower -> floating card; close X and tap outside.
4. 3 enemy variants march; 2 infantry defenders intercept where routes converge; health/armor bars track actual damage.
5. Sniper tracer, Guardiana orb/ice, Bombardera arcing shell/explosion all originate from tower and impact live enemy.
6. Pause, x2, restart, five practice waves work without duplicate starts.
7. Rotate portrait and back: rotation notice, no unintended advance during portrait.
8. Test 852×393 and 932×430 iPhone-like, 1024×768 tablet and 1440×900 desktop. Also test Android/iOS real hardware separately.
9. Capture before/after with matching pilot frame under the same screen size. Different levels of FX should be disclosed.
10. Do not merge into main, Canvas V5 or PixiJS without explicit authorization.
